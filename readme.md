## Description
A 2D local fighting game built with C++ and SFML, featuring animated character sprites, round-based combat, collision handling, pause flow, and modular screen/game management.

## Authors
-Vitalii Khymchuk
-Daria Havriuk

## Features by Vitalii Khymchuk
- Modular scene-based project structure.
- Fight loop, rounds, HP, win conditions.
- Player movement, gravity, jumping, blocking.
- Attack logic, cooldowns, damage, stamina.
- Active sprite switching, mirroring, scaling, rotation.
- Collision, opponent interaction, arena edge checks.
- Timer manager for delayed callbacks.

## Features by Daria Havriuk
- Menu modules and screen transitions.
- Menu design and development.
- Character sprites design and creation, animation frames.
- Shared drawable container for sprites, shapes, and text.
- Pause overlay texts and control hints.
- Draw order and foreground/background rendering.
- Sounds and audio.
